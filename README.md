# Deskrisi
Pengembangan sistem Backend onlineshope dnegan mengimplementasikan API menggunakan Node.js dan Express.js, 
serta mengintegrasikan database MongoDB untuk manajemen data. 
Fitur utama yang diterapkan antara lain CRUD (Create, Read, Update, Delete) untuk entitas tertentu,
autentikasi dan otorisasi pengguna menggunakan JWT (JSON Web Token), 
serta penerapan prinsip-prinsip dasar dalam pengembangan aplikasi web backend yang efisien dan aman.
